# NEAR PIN — ぴたり・おしいで番号を当てる

隠れた 3〜5 桁の数を当てる。予想すると、数字も場所も合った数「ぴたり」と、数字だけ合った数「おしい」が返ってくるので、手がかりを重ねて少ない回数でしぼり込む。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/near-pin/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

ヒット&ブロー、Bulls and Cows とも呼ばれる、紙と鉛筆の昔からの数当て。

1. 0〜9 の数字を重ならないように並べた、隠れた数を当てる（0 から始まってもよい）。
2. 予想を入れると、**ぴたり**（数字も場所も合っている）と **おしい**（数字は入っているが場所が違う）の数が返ってくる。
   例: 答え 0385、予想 3018 → ぴたり 0・おしい 3
3. 全部ぴたりになったら当たり。少ない回数で当てるほどよい。

| モード | 中身 |
|---|---|
| ひとり | 3 / 4 / 5 けたから選んで、何度でも。けたごとに最少回数を記録する |
| 今日の 1 問 | 4 けた。その日は誰でも同じ答え（端末の日付から作る）。1 日 1 回。連続日数と、何回で当てたかの分布が残る。結果は数字を見せずに ● ○ ・ で共有できる |

- 入力: 数字のボタン（入れた数字は押せない）、「消す」で 1 つ戻す、「決定」はけたがそろったときだけ。PC は数字キー・Backspace・Enter でも入れられる。
- 同じ予想をもう一度入れたら、判定は出すが回数に数えない。
- メモ: 0〜9 の札をタップすると、印なし → ×（入っていない）→ ○（入っている）と変わる。入力のボタンにも小さく出る。判定には使わない。
- 「あきらめる」は 2 回押すと答えを見せて終わる。
- 途中でやめても、次に開いたとき「続きから」で戻れる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 判定・答えの作り方・今日の 1 問・共有の文・保存のテスト（フレームワークなし）
```

| ファイル | 中身 |
|---|---|
| `logic.js` | 名前（`APP`）・答えの作り方・判定・今日の 1 問の答え・共有の文・保存する値の確かめ（DOM に触らない） |
| `main.js` | 画面の切り替え・入力・描画・音 |
| `test.mjs` | `logic.js` のテスト |

- 今日の 1 問の答え: 日付の文字列（`near-pin:YYYY-MM-DD`）を FNV-1a でハッシュして種にし、mulberry32 の乱数で 0〜9 を混ぜて先頭 4 つ。テストでいくつかの日の答えを固定しているので、作り方を変えると落ちる（変えると同じ日の答えが人によってずれる）。
- 保存は端末内の `localStorage`。
  - `near-pin.settings`: `{ v: 1, digits, sound, seenHelp }`
  - `near-pin.stats`: `{ v: 1, solo: { 3|4|5: { plays, wins, best, total } }, daily: { last, streak, maxStreak, dist: { 1〜10, more }, today } }`。`today` はその日の 1 問の続き・結果 `{ date, guesses, memo, done, gaveUp }`
  - `near-pin.game`: 途中のひとりのゲーム `{ v: 1, mode: 'solo', digits, answer, guesses, memo }`。終わったら消す
  - 読めない値や形のおかしい値は捨てて、はじめの値から。
- 元は自作の試作 2 本（Processing の numberguess、Java の Suziate）。ルールだけ受け継ぎ、コードは新しく書いた。
